     article?.title

8: Model、Record 的 getInt、getLong、getDate 等 getXxx 系方法支持将 String 转成所需类型

9: 新增 InformixDialect，支持 informix 数据库

11: Kv、Okv 的 getInt、getLong、getDate 等 getXxx 系方法支持将 String 转成所需类型

12: Ret 添加大量定制化配置，方便前后分离项目按需求定制 json 格式

13: Ret、Kv、Okv 新增 of(key, value) 方法

14: Ret 添加 ok(String msg) 与 fail(String msg) 方法，减少代码量

15: 新增 ScheduledKit，简化任务调度

16: 新增 ThreadPoolKit，简化线程池使用

17: redis Cache 新增 call 方法，支持如下用法：
   Long ret = Redis.use().call(jedis -> {

2：enjoy 引擎添加 #call 指令，支持调用模板函数时，函数名与函数参数动态化，进一步提升 enjoy 引擎的灵活性
